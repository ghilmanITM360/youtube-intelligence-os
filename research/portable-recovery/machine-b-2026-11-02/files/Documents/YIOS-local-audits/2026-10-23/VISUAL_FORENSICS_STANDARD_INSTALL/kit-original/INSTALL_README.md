Use ordinary natural-language triggers too: "visual forensics", "video CT scan", "frame-by-frame", "motion reconstruction", "video visual DNA", "deep video breakdown", "scene-by-scene visual analysis".

### Truth and measurement

- A source MP4's existence is distinct from its metadata, frame sampling, event verification, human sound listening, measured gaze, YouTube retention, and full AV sign-off.
- A 1fps sample never proves native-frame complete observation. A detector candidate is not a verified shot cut.
- Never generate invented CTR, attention percentages, emotional measurements, eye tracking, or precise lens/easing/software claims.
- Create prompts for NEW ORIGINAL videos expressing generalized production mechanics; do not silently pass off a replica of a third party's creative identity as original.
