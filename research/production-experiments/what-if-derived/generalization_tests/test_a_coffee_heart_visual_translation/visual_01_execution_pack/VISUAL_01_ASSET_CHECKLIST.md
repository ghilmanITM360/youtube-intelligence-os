## Do NOT create for Visual 01

| Item | Why |
|---|---|
| A second red strike | Revision 1 removed it. One strike in the whole video |
| A cross or X | The mark is one stroke |
| A version of IMG01 with the fork in it | Destroys the two word-anchored reveals |
| Generated `GOOD?` / `BAD?` images | Text is editor-native throughout the project |
| Any split export of IMG01 | Nothing is removed in this visual |
| Arrows, numbers, units, question-mark icons | Not in the plan, not in the narration |

## Generation order

```
1. IMG01     — sets the off-white value and the line weight for everything else
2. C01       — the character, needed as reference for Visuals 03 and 05
3. G02a + G02b — same session, so the two plates match
4. G03       — last, checked against the finished labels for legibility
```

Generate IMG01 first and sample its off-white and line weight. Every other
plate in the project has to match it.
