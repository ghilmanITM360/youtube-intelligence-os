# VISUAL 01 — ANIMATION PROMPTS

Four animations. Three are a layer switching on for one frame. One is a
four-frame wipe. That is the entire animation workload of Visual 01.

```
0 camera moves · 0 fades · 0 transitions · 0 generated video · 1 mask
```

**Placement rule.** Scrub the narration, find the onset frame of the anchor
word, put the operation on that frame. No offset, no padding, no lead-in.

---

## M01

```
Animation ID:     M01
Trigger phrase:   ON "good"  (w3)
Moving element:   G02a fork-left group + T01 GOOD?
Stays static:     off-white field, mug, heart
Camera:           STATIC
Tool:             CapCut — visibility switch on two layers, same frame
```
> The left branch line and its GOOD? label appear instantly in a single frame.
> The coffee mug, the heart and the background stay completely static.
> No camera motion.

## M04

```
Animation ID:     M04
Trigger phrase:   ON "wrong"  (w16)
Moving element:   G03 red strike stroke
Stays static:     everything else in frame, including Dr. Rehan
Camera:           STATIC
Tool:             CapCut — linear left-to-right wipe mask over the static PNG,
                  animated across 4 FRAMES ONLY, then holds
```
> The red strike quickly draws across the two answer branches in four frames.
> Coffee mug, heart, labels, doctor and background remain completely static.
> No camera motion.

**The four frames are the point.** 0.167s ESTIMATED. It must complete before
the next word is spoken — it is a flick of the pen, not a gesture spread across
the phrase "the wrong question." Spread over half a second it stops reading as
a strike and starts reading as an animation effect.
