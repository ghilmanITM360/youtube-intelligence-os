# VISUAL 01 — TEXT OVERLAYS

Two text elements. **Both are CapCut native text layers.** Neither is rendered
by an image generator — the two empty label plates come in as line art (G02a,
G02b) and the word is typed inside each one in the editor.

---

```
T01
Exact text:      GOOD?
Where:           Centred inside the LEFT label plate, x10–40%, y56–66%
Trigger:         ON "good" (w3) — same frame as the left fork half
Editor text:     YES. Never generated in an image
Style:           Black, same typeface and weight as every other text in the
                 video, all caps, centred in the plate
Purpose:         Names the first half of the binary on the word that says it
Leaves:          Never in this visual. Holds to the hard cut
```

```
T02
Exact text:      BAD?
Where:           Centred inside the RIGHT label plate, x60–90%, y56–66%
Trigger:         ON "bad" (w7) — same frame as the right fork half
Editor text:     YES. Never generated in an image
Style:           Identical to T01 — same typeface, same size, same weight,
                 same colour. Any difference reads as a preference
Purpose:         Completes the binary, so the viewer owns the model that is
                 about to be struck out
Leaves:          Never in this visual. Holds to the hard cut
```

## Mobile readability

Both words are five characters or fewer and each owns a plate spanning 30% of
the frame width — the easiest reading demand in the video. Still:

- Set the type large enough to fill most of the plate's width. Empty plates
  with small text read as a form, not as a diagram.
- `GOOD?` and `BAD?` must be **the same size**, not sized to fill their plates
  individually. `BAD?` is shorter; matching plate-fill would make it bigger and
  imply emphasis.
- The red strike (G03) crosses both plates. Check on an actual phone that both
  words are still readable under the stroke.
- Keep the question marks. They are what makes this a question being asked,
  not a verdict being given.

## Reappearance later — do not delete these layers

`GOOD?` and `BAD?` return in VISUAL 03 at a smaller size inside a compact
diagram, already visible at that shot's first frame. Same style, smaller size,
new position. Keep the text style saved.

## Rules

| Rule | Why |
|---|---|
| Appears on the word onset, no offset padding | Same anchoring rule as every other operation |
| Text and its plate appear in the SAME frame | They are one unit — a plate that arrives empty and fills a moment later reads as a mistake |
| No numbers, no units, no extra words | The narration supplies none |
