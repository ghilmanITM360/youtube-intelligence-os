# Script to video playbook

DRAFT knowledge-base document, prepared inside the audit folder (not a repository branch). Every rule below carries an ID in `RULE_EVIDENCE_LINKS`/`RULE_EVIDENCE_LEDGER.csv`; coverage and limits are in `WHAT_IF_RESEARCH_COVERAGE_AND_LIMITATIONS.md`. Review state: self-reviewed unless stated; no independent review exists. Rule classes: OBSERVED, MEASURED, INFERRED, HYPOTHESIS, OWNER.

Shape a draft against the measured baseline, not as a template: question stated and attributed (K01), a second beat that reframes it, an escalation chain the physics dictates, a button ending rather than a summary (K02), about 3.6 words per second (K04), a newer-era length reference near 630 words for a long video (K03). Plan the picture alongside the words: roughly one visual event per ten spoken words and one about every 2 s (K06, K07), a scene swap about every 40 words, narration from 0 s. Write each long script with Short seams marked: 38 of 40 Shorts are re-cuts (K05), and cuts have broken logic in four audited Shorts, so run a logic check on every seam. For each quantity decide label, axis, side-by-side, scale reference or worked calculation, and decide on purpose when the number is not shown (K14, K15). Every spoken physical number gets a recompute sheet (K19). Full script rules: `05_MASTER_SCRIPT_PLAYBOOK.md`.
