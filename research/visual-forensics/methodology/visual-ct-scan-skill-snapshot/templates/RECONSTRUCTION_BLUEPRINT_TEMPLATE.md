# Reusable production blueprint — original output inspired by measured techniques

## Originality and source trace
Source Video IDs/hashes; concrete transferable methods; original new art direction; avoid recreating a competitor's specific character, art or brand.

## Global design tokens
Aspect/resolution, type family descriptions, scale/hierarchy, colors (source-observed vs new palette), illustration treatment, lighting and texture, UI/chart vocabulary, minimum legibility/safe areas.

## Original assets and layer stack
Characters C01..; environments E01..; props O01..; graphics G01..; text T01..; audio A01..; continuity locks, availability/licensing, prepared variants.

## Timeline
For every state ID: source reference, original creative intent (hypothesis), original storyboard prompt, exact or bounded duration, moves vs static, camera path, scene transition, asset generation image prompt, animation prompt, negative constraints, sound plan pending approval.

## Production recipe
Storyboard -> design frames -> controlled assets -> image generation/illustration -> animation/keyframes -> compositing -> typography -> source-verified narration/audio -> mixing -> quality control -> export -> full review.

## QA and measurement
Source factual check; no missing overlay; natural frame-to-frame transition; continuity; genuine accessible text; native and 320px size review; real listening before AV pass; own-channel CTR/retention only when supplied; original creator/brand differentiation.
