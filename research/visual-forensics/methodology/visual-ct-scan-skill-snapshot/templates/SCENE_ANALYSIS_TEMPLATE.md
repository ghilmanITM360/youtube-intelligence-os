# Per-scene CT scan — scene {{shot_id}} ({{start_pts}}–{{end_pts}})

- **Source:** Video_ID; full SHA; native PTS and frame index; source thumbnails/frames.
- **Coverage:** sampling plus native frames reviewed, missed/uncertain gaps, verification label.
- **Objective visual facts:** subject/object IDs, positions and estimated screen proportions; foreground/midground/background; text exact as visible; color/lighting; framing; static anchors.
- **Change:** previous state → current state → next state; scene cut vs internal pose vs camera change; object appeared/disappeared/moved/resized/recolored/reframed.
- **Motion:** onset/anticipation/acceleration/action/settle/hold; measured frames/PTS if actually inspected; movement job and alternative.
- **Design:** silhouette, line/shape, hierarchy/grid, typography, palette, composition, negative space, art analogy (speculative), why static anchors matter.
- **Sound and script:** directly heard source? ASR only? verified word-to-graphic timing? Unavailable if not.
- **Attention hypotheses:** candidate look 1→2→3, curiosity/reveal/CTA, alternate reading, no synthetic CTR/retention.
- **Facial/performance:** expression, blink/gaze/gestures; only if visible.
- **Issues:** visual artifact, overlap/crowding, mathematical/on-screen number mismatch, continuity.
- **Reconstruction asset prompt:** subject, pose, environment, lighting, original style, aspect, coordinates, continuity, negative rules.
- **Animation prompt:** what moves/stays still, start/end states, timing, camera, overlay, static anchors, transitions, sound pending.
- **Editor plan:** shot duration; source/creative variant; layer order, QA acceptance and nearest-frame validation.
- **Assessment:** observed fact, measured change, inference and confidence separated; suggestion/effort/tradeoff/test.
