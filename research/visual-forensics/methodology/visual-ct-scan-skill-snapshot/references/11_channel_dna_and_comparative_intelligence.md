# 11 — Multi-video visual DNA and research comparability

## Unit of evidence

A source-ID–verified, properly time-covered video. A verified `VISUAL_ANALYSIS_PARTIAL` pilot can support **within-video observed** facts only. A channel-wide finding requires several relevant completed analyses, supporting IDs, weak counterexamples and transparency about the whole population.

## Channel visual DNA dimensions

- Signature characters / proportions / visual identity; line, shape, texture, rendering, lighting.
- Repeated environments / reusable backdrops / props / iconography / composition systems.
- Shot distribution, measured shot-length range if truly verified, transitions by actual shot vs within-shot events.
- Motion grammar: entrance/exit, gesture, camera, static anchors, overlays, kinetic typography, reveal/hold/settle.
- Title-thumbnail promise / introductory visual proof / callbacks, cliffhangers and payoffs.
- Audio grammar, only if heard: voice/music/SFX timing, loudness vs perceived synchronization.
- Production complexity and assets; visual consistency, color and typography tokens.
- Strengths / failure modes / alternative explanation / transferability to original content.

## Comparison matrix requirements

`channel | video IDs | sample n | source & hashes | dates | duration type | evidence level | behavior | median/range if measured | counterexample | potential confounders | confidence | original production lesson`.

Comparison strata: Shorts versus long-form; animated versus footage; distinct publication periods; source quality and coverage. Do not infer channel response from one pilot, and do not infer private CTR/retention from public view differences.
