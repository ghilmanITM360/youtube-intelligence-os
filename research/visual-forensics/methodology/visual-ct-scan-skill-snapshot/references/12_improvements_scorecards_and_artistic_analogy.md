# 12 — Improvement report, expert-style art critique, scorecard and influences

## All requested expert lenses, separate from evidence

- Fine art / conceptual: composition, symbolism, abstraction, rhythm, texture, scale, negative space, repetition, palette, cultural associations; compare to known artwork only as a reasoned *analogy*, never prove influence.
- Illustration: stroke quality, silhouette, character geometry, simplified forms, exaggeration, editorial metaphor, caricature, iconography, humor, visual narrative.
- Motion: movement job, timing/spacing, path, ease, anticipation, follow-through, secondary action, overshoot, squash/stretch, layers, masks, compositing, procedural vs hand animation (unknown unless verified), kinetic type, particles.
- Editorial design: grid, text hierarchy, contrast, alignment, whitespace, information density, legibility, design system, brand coherence.
- Camera/lighting: framing, staging, depth, apparent lens style (not exact lens), focus, parallax, practical/rim/key/fill evidence, simulated camera, stability.
- Color science: dominant/accent/secondary palette, temperature, saturation, luminance and accessibility, harmony if demonstrably applicable; psychological effects hypotheses only.
- Attention/story: visual metaphors, repetition, callback, narrative contrast, unresolved question, surprise, reveal and reward structure; never numeric attention/retention estimates.
- Production quality: asset sharpness, continuity, frame artifacts, render consistency, typography, audio if reviewed, alignment and polished motion.
- AI/stock/vector/3D provenance: confidence-limited appearance classification only; no claim of identified model/software/provider from pixels.
- Creators/design studios: any reference to Kusama, Richter, Koons, Ai Weiwei, Banksy, Hockney, Murakami, Niemann, Ngai, Mary Blair, Rockwell, Beatrix Potter, Kurzgesagt, Vox, Johnny Harris, Buck, Ordinary Folk, Apple, Pentagram etc. is **style analogy**, not proof of actual influence. Note observable shared design mechanism. Do not imitate exact branded content.

## Scorecard dimensions (1–10 if evidence)

Art direction; composition; color; motion design; typography; illustration; graphics; cinematography; editing; storytelling; emotional intent; premium perception; originality (source-specific and uncertain); predicted attention salience; retention-support hypotheses; brand consistency; eye-flow hypothesis; motion polish; information design; overall visual effectiveness. Per category include criteria, evidence/timestamp, counterexamples, confidence and `NOT_RATABLE` if insufficient footage. Scores are judgments with explicit anchors, NOT measured viewer metrics. Avoid false 2-decimal precision.

## Improvement list

For each suggestion: observed problem (timestamp); proposed specific change; expected mechanism (hypothesis); implementation recipe; effort/cost; negative trade-off; concrete acceptance test (e.g., readability, scene continuity); optional own-channel test metrics. Group by editorial, motion, scene design, accessibility, sound synchronization, information accuracy, continuity, rendering. Provide **up to 50 meaningful** interventions only when the owner explicitly requests 50; do not invent 50 filler improvements.

## Interpretation stages

**LITERAL FRAME → CHANGE → DESIGN PRINCIPLE → PLAUSIBLE FUNCTION → ALTERNATIVE INTERPRETATION → PRACTICAL RECONSTRUCTION/IMPROVEMENT → TEST**.

Never say ``red definitely increases dopamine`` or ``this creator used After Effects`` absent evidence.
