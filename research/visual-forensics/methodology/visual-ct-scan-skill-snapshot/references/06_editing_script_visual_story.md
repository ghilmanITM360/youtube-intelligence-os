# 06 — Editing architecture, scripting, visual storytelling, transitions and title/thumbnail alignment

## Distinct systems

- **Script engine**: title promise, actual spoken hook, question, setup/context, contradiction, reveal, example/proof, micro-payoff, wider payoff, reversal, callback, CTA/bridge. Distinguish fact-checking from visual behavior.
- **Visual engine**: map abstract concept to shot/asset/diagram, explicit literal/metaphor/comparison/proof; visual grammar and re-use.
- **Edit engine**: cut/hold/fade/wipe/dissolve/match/motion-match/morph, visual state changes within continuous shot; order and causal connection, time/speed/shot distribution only from verified boundaries.

## Every shot's narrative function

Opening hook / orientation / setup / evidence / explanation / anticipation / escalation / tension / payoff / reset / transition / joke / mood / CTA. Ask: WHY HERE? What viewer question exists, what new knowledge does visual add, what anchor continues, what previous visual sets up this one? Report creator purpose as inference, not directly observed intent. Compare before/after states and recognize purposeful static time.

## Visual-to-script crosswalk

For each key spoken phrase (timed if available): exact phrase/ASR qualification; visual evidence; relation `LITERAL`, `METAPHOR`, `DEMONSTRATIVE`, `DATA`, `CONTRAST`, `HUMOR`, `EMOTIONAL`, `DECORATIVE`, `POTENTIALLY_MISLEADING`. Record mismatched quantities, narration before/after motion, whether text simply repeats voice or makes interpretation easier.

## Editing metrics

Verified shots, median/mean durations, cuts per minute, hold distributions, novelty/visual state changes per minute, graphic overlay lifetime, recurring sequence template, intro-to-payoff span. **Only** compute after true boundaries and media coverage verified; never equate false camera zoom detections with hard cuts. Compare Shorts and long-form separately.

## Attention and payoff architecture

Track actual on-screen novelty, salient turns, held questions, micro-rewards, setup-payoff/callback structures and where information density spikes. No pretend retention curve or invented percentage. If private retention provided, compare actual graph to visual events with date/source and explicit confounders.

## Packaging

Thumbnail promise → title wording → first visible beat → opening spoken acknowledgement → evidence → payoff. The current image cannot certify upload-day thumbnail. Propose alternative titles/thumbnails only as original testable hypotheses, not measured CTR wins.

## Editor reconstruction formula

Per shot: asset/staging, text, motion cue, original narrative beat, handoff to next shot, audio role, pacing rationale, animation vs deliberate static anchor, acceptance screenshot/time references. Derive templates from multiple observed cases before declaring channel-wide standard.
