# Visual DNA

## Observed global rules

- **Character DNA:** black-outline stick figures; circular heads; minimal facial detail. Some figures add black hair, beard, glasses, or a wrapped head.
- **Environment DNA:** white paper-like field, sparse hand-drawn linework, thin black borders; scenes replace rather than share a literal continuous room.
- **Object DNA:** simplified black-outline appliances and props. Toaster red/orange glow is repeated visual shorthand for heat.
- **Palette / lighting:** near-white background, black line art, restrained red accent. Outdoor scene uses a grey night wash; title/end card use flat red.
- **Camera / composition:** locked, orthographic-looking wide compositions. Changes are primarily hard cuts or whole-frame replacements; no evidenced decorative camera drift.
- **Typography / graphics:** irregular hand-drawn uppercase and handwritten labels; scientific annotations use thin black type with red arrows/heat lines.
- **Depth:** flat 2D layers with rare soft red glow around hot appliances.
- **Motion language:** draw-on/reveal, state replacement, pop-in, opacity fade, and very short object/character pose swaps. Static holds dominate.
- **Transition language:** hard cuts, one early full-frame push/replacement, one fade-to-dark in outdoor scene, and red bumper/end-card cuts.
- **Asset reuse:** toaster, freezer/refrigerator motif, black-line character language, and red heat treatment recur across otherwise new plates.

## Scene exceptions

- S03 and S12 use branded red graphic cards rather than white line-art scenes.
- S10 is grey night exterior; its red toaster remains chromatic focal point.
- S08 is technical cutaway/diagram rather than character narrative.
