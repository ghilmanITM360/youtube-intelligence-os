# Visual DNA

All points below OBSERVED unless marked.

## Global rules

- **Character DNA:** sparse black/white stick figures, round blank heads, single-line limbs; pose changes are cut replacements, not visible limb interpolation.
- **Environment DNA:** hand-drawn black outlines, flat white/grey/black fills. Maps, diagrams and board inserts use intentionally uneven ink-like contours.
- **Object DNA:** paper, screen frames, checklist and TV use thin black outlines. Red only marks dimensions, waterlines, locators and regional callouts.
- **Palette / lighting:** white ground, light grey field/water/land, deep black silhouettes; muted red accent. No visible lighting evolution.
- **Camera / framing:** locked portrait 9:16 canvas. Most explanatory scenes stack a 16:9 upper illustration above a lower presenter field; map dashboard uses black lower half. No observed camera pan, zoom, parallax or shake.
- **Typography:** hand-drawn all-caps, black on white or white on black. Use editor text overlays for exact readable wording; original font UNKNOWN.
- **Depth:** graphic layering only. Grey water behind black silhouettes; red callouts above maps.
- **Motion language:** predominantly still holds, hard cuts, instant text/callout/pose replacements. S05 alone visibly depicts fast downward radial descent. S02 water curtain is a state fill, not proven fluid simulation.
- **Transition language:** hard cut or instantaneous state replacement; no verified dissolve, wipe or camera-driven transition.
- **Asset reuse:** E01 display frame, E08 map dashboard, E09 island tableau, C03 presenter and T01 typography recur. Red annotation set changes per depth state rather than accumulating.

## Scene exceptions

- S05 has full-frame radial streak motion and is only scene requiring continuous animation.
- S14 substitutes detailed exposed-seafloor map E10 for simple map E08.
- S16 uses a standalone news-card composition; no lower presenter field.
