## Reuse decisions
- S09 reuses IMG04's fully-escalated end frame (after its own F04.3 animation) verbatim as a static image — it is the same cross-section composition already established in S04; regenerating it would duplicate an asset the reference itself reuses.
- S13 does not get its own IMG entry: because S12's flash-impact animation (A17) already transitions the Moon from grey (IMG11's starting state) to its post-impact appearance, S13's flight animation (A18) continues directly from that same generation's last frame rather than starting a fresh image.
- IMG06 is generated wider than 9:16 specifically so the S06 camera pan (A11) can be produced as a crop/position animation over one plate instead of two separate images.
- IMG09, IMG10, and IMG11 all reuse the same small grey Moon icon design; they are still three separate image prompts because each sits in a materially different composition (shaded-Earth establishing shot, simplified-schematic diagram, and wide beam-only shot respectively).
