Global, repeated production patterns. Scene-specific detail lives in `TIMELINE.csv`; this file is not repeated there.

|---|---|---|
| CHARACTER DNA | One recurring minimal stick-figure (circle head, thin line limbs, holding a paper) in S01 only; a labeled human silhouette (line-art) in S02 only. No character reappears across shots. | No characters appear after S02; the rest of the video is diagrams/objects only. |

## Evidence and measurement conventions
- Frame numbering: 30fps constant frame rate, frame 0 = first video frame, frame 3717 = last (3718 total frames, 123.933333s).
- All IN/OUT values in `TIMELINE.csv` / `MOTION_EVENTS.csv` are frame numbers; DURATION is given as `frames/seconds`.
- Shot boundaries were located via ffmpeg scene-change scoring (`select='gt(scene,0.10)'`) cross-checked against dense (±0.2-0.4s) native-frame-rate windows around every candidate; sub-shot state boundaries and long continuous motions (the S08 ring wrap, the S13 comet flight) were confirmed via 1s/4s interval sampling rather than every native frame, so their exact boundary frame is a best estimate (±1s) rather than frame-perfect.
- "Static hold" means no materially different frame content was found across the sampled frames within that state's range.
