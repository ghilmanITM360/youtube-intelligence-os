# Visual beat maps — preliminary

Original diagrams only; these are conceptual directions, not produced assets. Each line names narration beat → physical meaning → proposed visual and misunderstanding to avoid. Shot-level asset lists and sentence-by-sentence maps remain to be completed.

## 01 Higher fall
- Two releases → compare starting height and arrival → split-screen identical objects and separate speed readouts; avoid depicting safety.
- Vacuum → acceleration without drag → remove atmosphere and grow downward velocity arrow; use an explicit vacuum label.
- Air restored → drag opposes motion → airflow and opposing arrows grow until balanced; do not imply gravity stops.
- Thin to dense → peak differs from final speed → draw a peaked speed curve alongside falling altitude; label illustrative model.
- Impact caveat → stopping conditions matter → same speed, different stopping distances; no survival claim.

## 02 Approved skydiver
- Closed parachute, downward fall → paradox → descending figure and shrinking speedometer; the ground continues to approach.
- Thin to dense air → increasing drag → show larger upward arrow; keep gravity arrow present.
- Drag exceeds weight → upward net force → compare arrows, not a reversal of motion.
- Model limitation → posture changes parameters → mark alternatives as uncalculated.

## 03 Voyager signal
- Transmit → signal travels → pulse leaves Earth on a clock; do not show a continuous physical trail as a literal object.
- Moon comparison → same light speed, different distances → nested distance ruler with broken scale.
- One light-day → milestone → expanding clock sweep reaching Voyager, dated Nov 2026.
- Reply → two legs → two distinct arrows and an extra processing-time block; avoid instantaneous reply being presented as real operations.

## 04 Tiny-world orbit
- Sideways jump → path bent by gravity → wide shot of figure and curved trajectory; distinguish imagined path from actual launch.
- Toy rock → assumptions → diagram R=3 km, density label, no atmosphere/spin/other body.
- Circular boundary → clearance problem → magnify contact point and show zero clearance for mathematical point.
- Upward launch → intersection → trace arc to first surface contact; dashed continuation inside rock is mathematical only.
- Elevated orbit and escape → compare paths → show safe clearance and open trajectory; no biomechanics promise.

## 05 Phobos
- Weak field → longer jump → show Mars and irregular moon, with time scale explicitly illustrative.
- Isolated sphere approximation → escape threshold → overlay smooth sphere with model speed; don't imply 11 m/s is a measured human jump.
- Real Mars system → competing gravity and rotation → change to qualitative arrows, not a predicted path.

## 06 Voyager repair
- Data unreadable → carrier versus content → coherent radio wave carrying scrambled blocks, not a silent transmitter.
- Memory readout → diagnosis → highlight corrupted region and label suspected chip; no invented cause.
- Relocation → code in separate slots → move blocks and reconnect references; no assertion that hardware was repaired.
- Delayed exchange → clock with two legs → label historical 22.5 h each direction; add processing time.
- Engineering return → staged recovery → show health packets first, later science; 2026 issue separate.

## 07 Lunar laser
- Pulse → round-trip clock → one outbound and one return arrow and ~2.5 s total.
- Retroreflector → light redirected → ray geometry with tiny fraction returned; no perfect mirror claim.
- Photon accumulation → many pulses and few detections → accumulate dots across shots; no single-shot precision claim.

## 08 Moonless ocean
- Removal stipulation → changing force, existing velocity → stop lunar arrows while water already in motion continues; avoid a physical disappearance mechanism.
- Differential pull → long waves → compare forces across Earth; do not portray two static real ocean mounds.
- Basins → complex response → wave turns at coast and dissipates; no invented surge height or timeframe.
- Solar forcing remains → new pattern → solar arrow persists; spring-neap interaction fades from schematic.

## 09 Solar tides
- Moon removed → solar force remains → show Earth and Sun on not-to-scale diagram.
- Differential pull → near versus far → compare arrow lengths after subtracting shared acceleration; avoid comparing total force to local tide height.
- Coast response → geography → two different basin outlines with qualitative waves; no numerical prediction.
