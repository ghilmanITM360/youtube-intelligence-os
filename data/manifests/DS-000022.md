## Recovery decision and limitations

No Apify recovery run was performed. The Lucas Grant workbook documents that the same ten videos returned no view count and no transcript on two separate scrapes. Those files contain explicit zero-word transcript placeholders, and the unavailable view values remain `N/A`. This is preserved source evidence, not a confirmed recoverable extraction failure. All 95 Lucas Grant video descriptions are present.

These packages are formatted exports rather than untouched Actor JSON. The dataset therefore does not claim original Actor raw evidence, Apify run IDs, or Apify dataset IDs. Metrics are point-in-time observations and may change on YouTube.

The main manifest and file ledger do not hash themselves because self-checksums are circular.
