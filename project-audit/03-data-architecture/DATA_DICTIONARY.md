# Data Dictionary

Part 1 is the **entity-level** dictionary: meaning, identifiers, source, ownership, quality and user value, written by the reviewer. Part 2 (appendix) is the **column-level** dictionary for all 7 SQLite stores, generated read-only from `PRAGMA table_info` / `foreign_key_list` with live row counts.

Ownership: every store is owned by the repository owner. Access today is filesystem-level (single user). First-party analytics are **private** and must never leave the owner's machine without separate authorization.
