# YIOS visual storyboard

Build original production plans from verified channel research. Preserve the distinction between observed source technique, source analyst interpretation, YIOS hypothesis and new creative choice.

## Source selection

1. Read `docs/intelligence/START_HERE.md`; choose the exact channel or ask if none was supplied.
2. Read that channel's entry point, source contract, status and limitations.
3. Prefer current reviewed source authority. For What If, read `research/visual-forensics/channels/CH-000004/CHANNEL_DNA.md`, then the 14-source Brain's canonical tables or DNA documents. The older three-video editing pilot is a narrower earlier sample; do not substitute it for the Brain.
4. For Casually Finance, use the protected published Visual Forensics branch and exact external checkpoint. Do not treat Video 003 as complete or the 38 limited-contract Shorts as full CT scans.
5. Resolve each cited observation to channel ID, video ID or source ID, exact file, and row or section. If source identity remains unresolved, cite source ID without inventing a YouTube ID.

## Output contract

Return, in this order:

1. Evidence used: exact source locators, status, what each supports, and material limits.
2. Storyboard: scene purpose, approximate timing (label estimates), narration segment, original visual action, on-screen text, transition and cited rationale.
3. Asset prompts: original composition, aspect ratio, layers, subject, background, consistency and rights constraints.
4. Motion and editing specification: events, sequence, estimated timing, keyframe behavior, text animation and narration mapping.
5. Validation: source links checked, unsupported claims, missing audio/visual proof, and human review still needed.

Use source patterns as design input, not as a template to copy competitor expression. Do not reuse source frames, distinctive illustrations, character designs, scripts, voice, music or exact scene sequences. Do not claim rendered video, measured timing for a new script, or audiovisual certification from a storyboard.

## Example request

"Use xkcd's What If? research to storyboard my original traffic-signal script." Read the channel entry point first, then inspect relevant source rows before invoking its fixed-frame or cut observations. Design a new traffic diagram and label those choices as original. Cite the Brain documents for measured corpus patterns; cite exact table rows if claiming a specific source-video moment.
