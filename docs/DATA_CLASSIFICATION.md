# Data Classification

Classification records two independent dimensions:

1. **Physical format** — for example ZIP, PDF, DOCX, Markdown, TXT, CSV, JSON, spreadsheet, image, transcript, or an as-yet unknown type.
2. **Semantic role** — the provisional evidence or intelligence class below.

File extension alone must never determine intelligence value. Never force uncertain material into the wrong category; use Unknown / Uncategorized until classification is supported.

## A. Global YouTube Knowledge

Examples include algorithm knowledge, storytelling, hooks, retention, titles, thumbnails, SEO, content strategy, audience psychology, monetization, and editing principles.

## B. Competitor Evidence

Examples include competitor screenshots, channel pages, video-page screenshots, titles, thumbnails, metadata, performance metrics, and competitor scripts.

## C. Forensic Video Intelligence

Examples include detailed video blueprints, script intelligence, visual intelligence, editing analysis, motion analysis, shot structures, retention analysis, and production grammar.

## D. Raw Forensic Evidence

Examples include thousands of extracted frames, OCR files, transcripts, motion metrics, audio analysis, state manifests, and intermediate analysis artifacts.

## E. Visual Reference Assets

Examples include selected keyframes, thumbnails, screenshots, and visual-state images.

## F. Channel-Specific Intelligence

Examples include a channel profile, target audience, previous videos, content calendar, analytics, past experiments, previous research, and channel-specific rules.

## G. Research

Examples include topic research, market research, scientific research, previous web research, and source notes.

## H. Unknown / Uncategorized

Anything that cannot yet be confidently classified. Uncertainty must be recorded, not hidden by a forced assignment.
