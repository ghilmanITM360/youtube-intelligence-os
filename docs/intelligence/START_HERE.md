## Load evidence progressively

1. Read selected channel's short entry point.
2. Read its source contract and evidence limitations.
3. Open exact source tables, video files, and row locators only when a claim needs them.
4. Label measured observations, source-declared interpretations, YIOS hypotheses, and new creative choices separately.

For an original script-to-storyboard task, use the project skill at
[`yios-visual-storyboard`](../../.claude/skills/yios-visual-storyboard/SKILL.md).

does not claim a rendered video or license to reuse competitor assets.

expected evidence and output format.
