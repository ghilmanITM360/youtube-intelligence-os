## Browser capture method (built-in browser pane, `mcp__Claude_Browser__*`)

Use `browser_batch`: navigate to `https://www.youtube.com/watch?v=ID` (or `/shorts/ID`), then a setup script defining:

- `profileVideo(rate=2)`: plays at 2x muted-to-user through `AudioContext.createMediaElementSource` into an AnalyserNode NOT connected to destination; samples RMS (p10/median/p90, share <0.01), hard cuts (mean 32x18 frame diff >40, ≥0.6 s apart), `dark_share` (luminance <3). Reuse the existing analyser if already connected (else "HTMLMediaElement already connected previously..."). Run in background storing to `window._res`; poll (JS tool times out at 45 s).
- `snap(t)`: seek, draw frame to fixed 800x450 overlay canvas `#_snap` (pane sometimes renders video blurred), wait 700 ms before screenshot (screenshot otherwise lags one frame). Read `.ytp-caption-segment` for captions.
- Ads: seek to ad end, verify `video.duration` matches expected before profiling. Discard any profile taken on an ad.
- Shorts autoplay navigates away at end: profile first, clamp snaps to duration − 1.2 s.
- Audio is measured as levels only, never "heard"; label accordingly.
