# Research preflight and reusable audit template

Required before finance, health, history or other niche research. This implements the repository's [provenance requirements](../../docs/PROVENANCE.md) and [classification boundaries](../../docs/DATA_CLASSIFICATION.md).

- [ ] Read the [master index](MASTER_INDEX.md), relevant topic documents and [limitations](LIMITATIONS_AND_MYTHS.md).
- [ ] Inspect the saved source catalog, branch index, prior reports and active PRs for duplicate work.
- [ ] Reuse existing channel IDs, video datasets, transcripts and thumbnail evidence. Do not promote research-only sources into canonical registries.
- [ ] Record snapshot/collection date, publication date and source version separately. Check whether freshness fits the question.
- [ ] Deduplicate SHA256, archive members, video IDs and export/summary source families.
- [ ] Identify missing metadata, captions, images, visual review and private analytics; never infer missing observations.
- [ ] Separate observed performance from hypotheses about causation. Preserve channel/format/age cohorts and denominators.
- [ ] Cite original source IDs, paths/URLs, timestamps/pages/rows and dates for each substantive conclusion.
- [ ] Check important platform claims against current official documentation if the prior verification is insufficient for the decision.
- [ ] Check five-hour usage first, weekly second, context warnings third. Stop near 90% / 95%; unknown indicators stay UNKNOWN.
- [ ] Confirm authorized phase, allowed tools/costs, Git scope and source-preservation checks.
