# SEO and distribution

**SOURCE_OPINION.** DS-000011's SEO checklist provides a keyword/topic and metadata review sequence. It is a checklist, not proof that keyword density or tags cause ranking. [Source manifest](../../data/manifests/DS-000011.md).

**OFFICIAL_CURRENT — checked 2026-10-15.** Search considers relevance, engagement and quality. Title, description, tags and video content can inform relevance to a query; watch time for that query and viewer history can also matter. [How YouTube search works](https://support.google.com/youtube/answer/16090438).

Tags primarily help with spelling variants and are not essential for discovery. [YouTube metadata guidance](https://support.google.com/youtube/answer/16559650).

The Data API video resource documents a 100-character title and 5,000-byte description limit. Owner-only fields cannot be assumed available for competitors; dislike counts require owner authentication. A public metadata resource is not private Studio analytics. [Video resource documentation](https://developers.google.com/youtube/data/reference/rest/v3/videos).

**Project boundary.** API documentation was read only to verify limitations. No API integration, scraping or competitor acquisition was performed. User-supplied files remain the competitor workflow; see [AGENTS.md](../../AGENTS.md).
