# YouTube knowledge base

Start with [research preflight](RESEARCH_PREFLIGHT.md), then [master index](MASTER_INDEX.md). This is a source-preserving recovery index, established 2026-10-15, not a fresh generic strategy guide or a canonical-data promotion.

[Source catalog](SOURCE_CATALOG.csv) locates physical sources and exact SHA256 duplicates. [Branch index](BRANCH_SOURCE_INDEX.csv) preserves immutable Git locators for versions outside main. [Drive discovery](DRIVE_DISCOVERY.json) records accessible cloud candidates. [Knowledge map](KNOWLEDGE_MAP.md) routes questions to evidence. [Handoff](HANDOFF.md) is the authoritative resume point.

Evidence labels: OFFICIAL_CURRENT = checked official page on stated date; SOURCE_OPINION = creator advice; OBSERVATION = dated source measurement; AI_INTERPRETATION = analyst synthesis; HYPOTHESIS = proposition requiring a test. An impressive filename, including “Verified”, does not establish authority.

Local-file dates in the catalog are filesystem modification times, not measurement dates. No catalog row count is a count of independent studies. Original files remain in place. Local-only sources require backup verification before using another computer.
