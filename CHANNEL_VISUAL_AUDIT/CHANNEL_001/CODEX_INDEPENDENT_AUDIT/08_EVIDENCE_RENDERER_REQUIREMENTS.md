# Authentic document animation in the existing renderer

R9b routes through the existing beat and layer renderer. It already composites original asset layers and draws source tags, paths and rings. The sampled V1 scenes use diagrams, text annotations and source tags. The missing integrated operation is an authentic capture with a viewport and document-registered annotation. An existing ring primitive can be reused. No new engine is necessary.

**Input.** Each document instance has a claim ID, file and SHA-256, canonical URL, publisher/title, retrieved date and archive or data vintage, rights basis, exact verified passage or cell, full-image dimensions, normalized target coordinates, and retained units, headers, qualifiers and periods. Keep the capture immutable. Render derived images separately. Evidence tags remain individually readable with each source in a comparison.

**Composition.** Render a document-local group with image, translucent yellow rectangles or paths and red stroke paths. Clip the group to a defined viewport, then place it on the output canvas. Specify crop in source pixels and anchor/fit/scale explicitly. For zoom or panning, apply one transform to the image and document-local annotations every frame. A comparison label or source tag can be canvas-fixed. Ring path progress, stroke width, marker opacity and underline direction are independent of camera motion. Support on-entry marks, instantaneous additions, a progressive reveal and persistence. A highlight may coexist with a pre-existing numeral or annotation. The software behind the reference effect is unknown.

**Timing.** Track first source pixel, first legible target, first marker pixel, draw-on onset/completion, hold and exit as separate frame-addressable events. Place the marker at the approved spoken clause using verified voice timing. Choose a readable lead-in or pre-marked entry when the figure is spoken immediately. Drop any preset based on the invalid 4.8 s semantic interpretation.

**Acceptance.** A small proof in a separately authorized production uses one rights-cleared real table or document and its capture manifest. Verify original SHA, exact passage entailment and visible context with independent review. Inspect first visible, pre-mark, midpoint, completion, zoom, hold and exit frames. Confirm no drift, quote obstruction, crop leakage or competing marks. Check a phone-size playback and a 25% display proxy for value, unit, date and publisher. A full document and a focused readable view may need separate beats. If a primary capture cannot be cleared or read, use an attributed redraw with retained source data and an explicit design decision. No proof or R9b rerender was performed for this audit.
